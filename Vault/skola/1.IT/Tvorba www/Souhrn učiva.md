# Tvorba WWW

Předmět zaměřený na základy tvorby webových stránek pomocí HTML a CSS (původně složka TWS).

## 🌐 Témata a okruhy, které se probíraly:

### 1. HTML5 - Struktura webu
- **Základy HTML**: Odkazy, odstavce, nadpisy.
- **Sémantika a struktura**: Seznamy (přehled sportů), Tabulky (Piškvorky, tabulky týmů a předmětů).
- **Formuláře**: Úvod do formulářů, objednávka dinosaura, registrace WoW postavy, LEGO formulář.

### 2. CSS3 - Kaskádové styly a design
- **Způsoby zápisu**: Inline, Interní, Externí.
- **Stylování**: Úprava textu, zarovnání textu, pseudo-třídy (hover apod.).
- **Pozicování a Layout**: Pozicování prvků (Putování s dinosaury, profilové stránky).
- **Moderní design**: Light-Dark theme.

### 3. Tvorba celistvých projektů
V rámci ročníku vzniklo několik komplexních stránek:
- Web Česká a italská kuchyně
- Skateboarding
- Stránka kapely Dune Rats / Linkin Park
- Herní portál, Web o USA
- Mexická restaurace (Nacho Libre)
